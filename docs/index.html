Daybreak Brief

Technical Lead

An automated news briefing product built as four services chained on a GitHub Actions schedule, backed by Supabase.

  • get-articles pulls tracked topics and domains from Supabase, then queries the GDELT news index for that day's coverage.
  • scrape-and-clean fetches and cleans the full article text behind each result.
  • score-articles embeds every article (MiniLM, 384-dim), drops near-duplicates by cosine similarity, clusters by topic with DBSCAN, and scores each one on topic importance and cluster centrality.
  • summarise-and-send deduplicates the day's scored set, summarises it with an LLM, and sends the newsletter.
  • A Flask + Supabase site handles the public front end, Stripe billing, and rate-limited routes.
Learned most of a pipeline's quality comes from the scoring and dedup logic upstream, not the LLM step everyone assumes matters most.

Personal & Hobby Projects

CIFAR-10 Convolutional Neural Network

A from-scratch CNN classifier: three conv blocks (32/64/128 filters) with batch norm and dropout that increases with depth (0.2 → 0.3 → 0.4), built-in RandomFlip/RandomTranslation augmentation, and an Adam optimizer with ReduceLROnPlateau. Reaches roughly 83-86% test accuracy after 40 epochs.

GitHub Actions lints and smoke-tests the training script on every push · source

NumPy MLP from Scratch

A multi-layer perceptron with forward pass, backpropagation, and gradient updates written by hand in NumPy, no PyTorch, no TensorFlow, no autograd. Xavier-initialized weights, tanh/sigmoid/ReLU activations, and both batch and online (stochastic) training loops implemented separately so their convergence behaviour can be compared directly.

93 unit tests, 100% line coverage in CI · live demo · source

Ball Tracker
